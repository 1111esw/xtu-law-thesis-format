# 排版要求

依据附件1明确批注，并应用用户明确要求的页眉留空修改。三号16pt、四号14pt、小四12pt、五号10.5pt、小五9pt。中文为宋体，英文数字为Times New Roman；以下特殊说明优先于正文默认。

中文主题字体标题和正文分别对应WPS的“宋体（标题）”“宋体（正文）”；括号内容是主题角色，不是字体文件名。英文和数字在两个主题角色中都对应Times New Roman。

## 页面 正文 页眉页码

| 项目 | 要求 |
|---|---|
| 页面 | A4，21×29.7厘米 |
| 页边距 | 上3厘米、下2.5厘米、左3厘米、右2厘米 |
| 正文 | 宋体小四；两端对齐，首行缩进2字符，段前段后0行，固定值20磅 |
| 起页 | 正文从奇数页开始，各章另起一页；不是每章都要求另起奇数页 |
| 页眉 | 全文留空，不写任何内容，不加图案、字段或装饰线；检查各分节默认、首页和偶数页页眉及继承关系 |
| 页眉页脚边距 | 页眉距边界1.5厘米，页脚距边界1.75厘米 |
| 前置页码 | 从摘要开始，摘要、Abstract、目录等用大写罗马数字Ⅰ、Ⅱ、Ⅲ连续编排 |
| 正文页码 | 从“一、绪论”起用阿拉伯数字从1重新编至文末 |
| 页码字形 | 页面底部居中，Times New Roman小五；不加横线等修饰 |

用户指定全文页眉留空，包含封面、附三件、摘要、正文和附录。模板原有页眉从工作副本中清除，技能保留的原件不修改。保留页脚及页码。过程材料见process-materials.md。

## 正文标题

各级标题两端对齐、首行缩进2字符、固定值20磅，大纲级别与标题级别一致。

| 级别 | 编号 | 字号和加粗 | 段前 | 段后 |
|---|---|---|---|---|
| 一级 | 一、 二、 三、 | 三号，加粗 | 24磅 | 18磅 |
| 二级 | （一） （二） | 四号，加粗 | 24磅 | 6磅 |
| 三级 | 1. 2. | 小四，加粗 | 12磅 | 6磅 |
| 四级 | (1) (2) | 小四，不要求加粗 | 6磅 | 6磅 |

章节批注要求题序与标题之间空1格。一级编号有顿号；括号编号后不再加顿号。不能将“一、”改成“一 ”，也不能用黑体替代规定的宋体。

## 中文摘要

- 另起一页。标题“摘    要”，两字间空2个汉字空格或4个半角空格；宋体三号加粗，居中无缩进，大纲1级，段前段后0行，单倍行距。
- 内容宋体五号，西文Times New Roman；两端对齐，首行缩进2字符，段前段后各0.5行，固定值20磅。
- 摘要不要出现“本文”。不据此删掉必要的对象、方法、观点或结论。
- 关键词前空1行。“关键词：”宋体小四加粗，内容宋体五号、西文Times New Roman；两端对齐，首行缩进2字符，段前段后0，固定值20磅。
- 用全角分号“；”分隔，最后不加标点；一般不加引号和书名号。附件2允许空格或分号，排版优先按模板明确的分号样式。
- 两份文件未明确中文摘要的统一字数；鉴定意见内容提要约400字不是摘要字数规定。

## 英文摘要

- 另起一页。Abstract为Times New Roman三号，居中无缩进，大纲1级，段前段后0，单倍行距；批注未明确加粗。
- 内容Times New Roman小四，两端对齐，首行缩进2字符，段前段后各0.5行，固定值20磅；英文标点后留1个半角空格。
- 关键词前空1行。“Key words:”Times New Roman小四加粗，内容小四；两端对齐，首行缩进2字符，段前段后0，固定值20磅。
- 用半角分号“;”分隔，最后不加标点。

## 目录

- 另起一页，包含摘要和Abstract，显示到三级；第四级及以后不显示。
- 标题“目    录”，两字间空2个汉字空格或4个半角空格；宋体三号加粗，居中无缩进，段前24磅、段后18磅，固定值20磅。
- 一级目录项宋体四号，二三级宋体小四；西文均为Times New Roman。各级两端对齐，无首行缩进，右缩进0，段前段后0，1.5倍行距。
- 一级左缩进0、二级2字符、三级4字符。
- 页码右对齐，带前导符；修改正文后刷新目录。目录里的“摘要”“附录”“致谢”不夹空格。
- 目录1.5倍行距是独立设置，不用于正文。

## 图 表 公式

| 项目 | 要求 |
|---|---|
| 表题 | 表上方，宋体五号加粗，西文Times New Roman；居中无缩进，段前12磅、段后6磅，单倍行距 |
| 表编号 | 示例“表1-1 表名”，编号和名称间空一格；表名中不用标点，末尾不加标点 |
| 图题 | 图下方，宋体五号加粗，西文Times New Roman；居中无缩进，段前6磅、段后12磅，单倍行距 |
| 图编号 | 示例“图1-1 图名”，编号和名称间空一格，末尾不加标点 |
| 图表注及来源 | 宋体小五、西文Times New Roman，两端对齐，首行缩进2字符，段前段后0，固定值20磅；按需要添加 |
| 跨页表 | 后续页重复表号，标“续表1-2 表名”，重复表头 |
| 分图 | (a)、(b)、(c)编号，各分图名在各自图下，主图名在全部分图下方居中 |

- 来源说明可用页下注或置于图表下方。图表下说明不与其他脚注连续编号。
- 引用完整图表用“图形来源”“图片来源”或“表格来源”；自己制作但数据引自其他文献用“数据来源”。不同性质说明按来源、整体说明、局部说明排列。来源不得虚构。
- 公式超过1个即编号。数量少全篇编号(1)，多可分章编号(1-1)；编号置于括号内、右对齐。批注要求公式与编号间以“...”连接。公式段落可用最小值20磅，避免裁切。
- 不自行添加彩色装饰或学校未要求的特殊图表样式；复现模板时保留相关表格结构。

## 参考文献 致谢 附录

- “参考文献”另起一页，宋体三号加粗，居中无缩进，大纲1级，段前24磅、段后18磅，固定值20磅。条目著录见citations.md。批注未独立规定条目字号及段落参数，不自行补成学校要求；需严格复现时查看保留模板。
- “致    谢”另起一页，间隔同摘要；宋体三号加粗，居中无缩进，大纲1级，段前24磅、段后18磅，固定值20磅。正文按正文小四格式。
- 附录可含检测报告、程序、译文及原件等，用A、B、C排序，各附录另起一页；附录A示例为论文检测报告简版，没有其他内容时删除无内容的附录B。
- 附录标题宋体三号加粗、西文Times New Roman，大纲1级，两端对齐、首行缩进2字符，段前24磅、段后18磅，固定值20磅。
- 附录内容宋体五号、西文Times New Roman，两端对齐、首行缩进2字符，段前段后0，固定值20磅。
- 附录图表公式与正文分开编号，冠附录字母，如图A1、表B2、式(B3)。
