# WPS字体与空白页眉

用户主要用WPS。目标是文档声明正确且目标软件实际能调用所需字体，不仅是界面上出现“宋体”二字。

## 中文和西文字体

- 按用户截图指定主题对应：“宋体（标题）”为中文标题主题，“宋体（正文）”为中文正文主题；两者的实际字体名称均写“宋体”，不能把带括号的界面标签当作字体名称写入文件。
- 在`a:fontScheme`中，将`majorFont`和`minorFont`的`a:ea/@typeface`及`a:font[@script=Hans]/@typeface`均设为宋体；两者的`a:latin/@typeface`均设为Times New Roman。主题语言`w:themeFontLang/@w:eastAsia`为zh-CN。
- 标题及关联的标题字符样式使用`eastAsiaTheme=majorEastAsia`，正文、表格正文、目录、脚注及相应默认使用`eastAsiaTheme=minorEastAsia`，同时显式声明`eastAsia=宋体`。西文直接设置Times New Roman，清除冲突的`asciiTheme`/`hAnsiTheme`。标题角色靠主题与样式设置，不是另换一种宋体。
- 中文目标宋体，常见英文名称SimSun；英文和数字Times New Roman，字号随段落。
- 不自动把Songti SC、SimSong、STSong等别的字体视为相同字体；字体家族、字形和软件别名需实际核对。系统内有某种“宋”字体不证明有指定宋体。
- OOXML中显式设置`w:rFonts/@w:eastAsia`为宋体或经目标软件验证的SimSun名称；`ascii`与`hAnsi`为Times New Roman。可用`hint=eastAsia`及`w:lang/@w:eastAsia=zh-CN`帮助识别中文；保留正确的英文槽，不把混合段落全部改成一种字体。
- 检查文档默认、正文和标题样式、链接字符样式、目录、表格、正文直接格式、脚注、尾注、超链接、页脚和编号。数学符号、图标等有专用字体时不盲目替换。
- 去除冲突的主题覆盖；已经正确指向宋体的`majorEastAsia`或`minorEastAsia`保留。不要把保留中文主题角色与保留Calibri/Cambria西文覆盖混淆。继承链可能在直接格式之外影响实际字形。
- 核对fontTable中宋体/SimSun和Times New Roman的声明及必要别名。字体表只是名称与属性的声明，不代表字体已经安装；不能凭添加声明宣称已解决字体缺失。

## 排查与验证

1. 读取用户指出的实际DOCX，检查字体声明和继承，保留原件。
2. 检查系统字体和目标软件提示。macOS系统字体解析与WPS、Word的私有字体来源可能不同，系统结果只是线索。
   - 系统名称查询落到默认字体，不证明电脑或应用没有宋体；应用安装包可能自带真正的SimSun字体文件，须核对文件内部的字体家族与中文名称。
   - WPS泛化的“缺失字体”提示不证明缺的是宋体。先确认具体缺失字体名称；文档fontTable也可能保留未使用的旧字体，不能凭总提示作宋体缺失结论。
3. 在可用且适合的情况下用WPS查看该文档、中文正文与标题、英文数字、脚注及页码，关注“缺失字体”提示。混合文字的工具栏只显示单个名称，不能据此证明所有字符字体正确。
4. 若WPS缺少宋体，明确说明缺字体现象；修正文档声明不能自动提供实际字体。不擅自安装字体、把Office私有字体复制到系统或改变WPS全局替换设置；需要这种操作时先界定具体方案与用户意图。
5. 若需要替代字体，由用户确定替代选择；记录它是有意偏离原来的宋体要求，不写成完全符合学校字体规范。
6. 按文档技能完成渲染检查，但分别报告结构核对、渲染检查、WPS检查和Word检查的实际范围。未打开Word不宣称Word显示正常；未解决缺失字体不宣称WPS宋体问题已解决。

可运行`scripts/check_docx_compatibility.py`进行只读检查。它报告各文档部件的直接字体声明、主题字体覆盖、可见页眉残留，以及macOS系统字体名称解析。它不完整解析样式继承、不检测应用私有字体、不替代目标软件验证。

需要应用这些设置时，可使用`scripts/apply_font_roles.py 输入.docx --out 输出.docx`。该处理器更新主题、普通文本字体与空白页眉；保留内容、字号、段落、页脚及数学/符号专用字体。不覆盖原件。处理后检查输出再交付，不将结构检查当作WPS实测。

## 页眉

- 用户要求所有页眉为空，优先于原模板中的校名页眉说明。
- 遍历全部分节的默认、首页、偶数页页眉及链接关系，清除文本、字段、图片、水印、表格内容和段落装饰线；空段落可以保留。
- 不靠关闭“首页不同”或“奇偶页不同”掩盖旧页眉；检查不再显示旧内容。
- 页脚页码按既有规则保留。不要删除全部页眉页脚而误删页码。
- 保留模板原件，工作副本应用新的空白页眉规则。
