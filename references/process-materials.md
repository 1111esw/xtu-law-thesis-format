# 过程材料及提交

依据附件1正文和批注。张三四、李五六、认罪认罚论文题目、2024—2025日期、民营企业和农村消费范文是样例，不能成为用户事实。

## 装订及电子版本

- 胶装顺序：封面 → 任务书 → 评阅表 → 鉴定意见 → 中文摘要 → 英文摘要 → 目录 → 正文 → 结论 → 参考文献 → 致谢 → 附录。
- 封面白色木纹纸，其他部分A4双面打印，胶装。
- 任务书、评阅表、鉴定意见为“附三件”，纸质版包含并按要求签字盖章。
- 格子达论文上传版本不含附三件，过程材料从单独入口上传。生成文件不默认授权上传。
- 原模板已要求附三件和鉴定意见无论文页眉；用户进一步指定全文页眉均留空，不写任何内容。
- 模板另含开题报告和中期检查表，不自动插入论文正文。

## 信息填写

- 班级按教务系统全称，规则示例为年级＋专业＋几班。
- 专业全称：法学、知识产权、信用风险管理与法律防控、知识产权（第二学士学位）、法学（辅修）。按用户事实选用，不由文件路径推定。
- 任务书系主任栏，批注要求填导师所在学科组组长姓名。
- 姓名、学号、专业、导师、签名、日期、成绩依据实际资料，不继承模板占位内容。

## 任务书

- 栏目：主要内容及基本要求、重点研究问题、进度安排、资料及主要参考文献。
- 常规中文宋体、西文Times New Roman、小四。
- 主要内容及基本要求对应批注：两端对齐，首行缩进2字符，段前段后各0.5行，固定值22磅。
- 重点研究问题对应批注：中文宋体带下划线、西文Times New Roman、小四，两端对齐，首行缩进2字符，各独立部分用1、2、3重新编号；段前段后0，固定值22磅。下划线只用于对应栏位。
- 任务书要求搜集、精读、归纳有关文献不少于10篇，综述需有观点提炼、引用和评析。
- 正文不少于10000字注明“仅参考，具体要求学院自定”，不视为已确认的统一字数要求。
- 完成时间按学部当年安排填写，辅修按实际进度，不照抄旧时间表。

## 评阅与鉴定意见

- 评阅表须保留能否答辩的结论；评阅人不能是指导教师，批注要求电子签名。不得代造签名。
- 日期顺序：指导教师 → 评阅人 → 答辩小组组长 → 答辩委员会主任，不据格式需要编造时间。
- 鉴定意见是毕业档案材料，个人信息必须准确；内容提要约400字，扼要、客观介绍对象、观点、论据、结论或建议及创新。此字数不是摘要要求。
- 成绩五等：优秀、良好、中等、及格、不及格；成绩文字宋体小四、加粗、下划线。
- 导师评语关注论文质量、平时态度和能力；答辩评语关注陈述和答问，与成绩匹配。不把占位评语当作已出具的实际评价。

## 开题及中期检查

- 开题报告：目的意义、国内外综述、提纲、完成计划，导师、学科组及学院意见。
- 中期检查：研究方向、已完成任务与进度、待完成任务、是否能按期完成、问题与拟采取办法、已读文献及相关意见。
- 用户要求填写时按实际进展整理，相关意见、签名、日期没有依据时保留待填写。

结论概括自己的研究成果，区分本人、导师与他人成果；“首次”“领先”“填补空白”须有足够依据，不能为润色而添加。
